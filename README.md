## 🚀 Featured Projects

### 🗄️ [Mini HDFS Simulation](https://github.com/Retesh07)
`Python` `TCP Sockets` `Flask` `Multi-threading` `Distributed Systems`
- Fault-tolerant distributed file storage system modeled on HDFS — zero data loss across simulated Datanode failures via 2MB chunk-based storage with automatic 2x replication
- Namenode–Datanode communication over TCP sockets with heartbeat-based failure detection and multi-threaded concurrent request handling
- Flask-based web dashboard for live cluster health monitoring, system logs, and one-click upload/download

### ✈️ [YatrAI](https://github.com/Retesh07)
`React` `Node.js` `Express.js` `MongoDB` `Redis` `Socket.io` `BullMQ`
- Full-stack AI travel-itinerary platform with JWT auth (access tokens + httpOnly refresh cookies), RESTful Express.js API, and real-time Socket.io notifications
- Asynchronous background job pipeline using BullMQ and Redis to decouple notifications from the request thread, with graceful synchronous fallback

### 🧠 [DocMind AI](https://github.com/Retesh07)
`LangGraph` `ChromaDB` `Groq LLM` `RAGAS` `LangSmith`
- Agentic RAG pipeline in LangGraph with 5 conditional nodes (Retriever, Grader, Generator, Query Rewriter, Hallucination Checker) — 0.75+ Answer Relevancy & Context Precision on RAGAS
- Diagnosed and fixed a duplicate-chunk vector DB bug degrading MMR retrieval diversity; full LangSmith observability across every node

### 🗃️ [AI SQL Assistant](https://github.com/Retesh07)
`Python` `FastAPI` `Groq API` `SQLite` `MySQL` `JavaScript`
- Natural-language-to-SQL platform with FastAPI and Groq-hosted Llama 3.3 70B — schema-aware SQL generation across SQLite and MySQL
- Relevance-detection and SQL validation layer blocking unsafe/out-of-scope queries, with natural-language explanations, Chart.js visualizations, and CSV export — deployed live on Render
